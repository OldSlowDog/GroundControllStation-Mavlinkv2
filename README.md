# INAV Stellar Ground Control Station (GCS)

## 📌 项目简介

**飞控上位机调试软件** - 用于连接 INAV Stellar 飞控系统进行实时调试、参数调优、传感器校准和数据记录的专业工具。

基于 **Python + PyQt5** 开发，采用现代化的深色主题界面，提供直观的可视化操作体验。

---

## ✨ 功能特性

### 🔌 连接与通信
- 自动检测可用串口设备
- 支持多种波特率配置（115200/57600/38400/9600）
- MSP协议实时数据收发（20Hz刷新率）
- 断线自动重连机制

### 📊 实时数据监控
- **姿态显示**: 地平仪仪表盘（Roll/Pitch/Yaw）
- **传感器数据**: 实时曲线图表
  - 陀螺仪三轴数据（°/s）
  - 加速度计三轴数据（g）
  - 磁力计数据
- **电机输出**: 四路PWM实时监控
- **遥控器输入**: 8通道RC数据显示

### ⚙️ 参数调优
- PID参数可视化编辑表格
- 一键从飞控读取/写入PID参数
- 支持ROLL/PITCH/YAW独立调节
- 参数重置为默认值功能

### 🎯 校准功能
- IMU加速度计校准（水平面校准）
- 陀螺仪零偏校准
- 遥控器中点校准
- 电调行程校准（安全提示）
- 磁力计8字形校准

### 💾 数据记录与回放
- CSV格式飞行数据记录
- JSON数据导出功能
- 飞行统计信息（最大高度、飞行时间、数据率等）
- 历史数据管理

### 💬 终端日志
- 实时通信日志显示
- 手动命令发送接口
- 时间戳标记

## 📖 使用指南

### 1. 连接飞控

1. 使用USB-C数据线连接电脑和飞控开发板
2. 打开软件后，点击"刷新"按钮扫描串口
3. 选择正确的串口号（通常为 COM3-COM10）
4. 保持默认波特率 115200
5. 点击"🔌 连接"按钮

**成功标志：**
- 状态栏显示"● 已连接"（绿色）
- 右侧面板开始显示实时数据

### 2. 监控飞行数据

连接成功后，软件会自动以20Hz频率请求并显示：

- **左侧面板**：
  - 地平仪：显示飞机当前姿态角
  - 仪表盘：电池电压、电流、高度、油门
  - RC通道：所有遥控器输入值

- **右侧标签页**：
  - "实时监控"：传感器原始数据和电机输出曲线
  - "终端日志"：MSP通信记录

### 3. 调整PID参数

1. 切换到"⚙️ PID调参"标签页
2. 点击"📥 从飞控读取"获取当前参数
3. 在表格中修改P/I/D值
4. 点击"📤 发送到飞控"应用更改
5. 观察飞行表现进行微调

**注意事项：**
- 修改参数前请确保已解锁（ARMED）状态
- 建议每次只调整一个参数
- D值过大可能导致震荡

### 4. 执行校准

根据需要选择相应的校准类型：

- **IMU加速度计**：将飞控放置在水平面上
- **陀螺仪**：保持飞控完全静止
- **遥控器中点**：所有摇杆置于中间位置
- **电调**：⚠️ 必须拆除螺旋桨！
- **磁力计**：手持飞控做8字形旋转

### 5. 记录飞行数据

1. 切换到"💾 数据记录"标签页
2. 点击"⏺ 开始记录"
3. 进行测试飞行或调试操作
4. 点击"⏹ 停止记录"
5. 数据自动保存至 `logs/` 目录

导出格式：
- CSV：适合Excel分析
- JSON：适合程序处理

## ⌨️ 快捷键与命令

### 串口命令（在终端标签页输入）

| 命令 | 说明 |
|------|------|
| `a` 或 `A` | 解锁飞控（ARM） |
| `d` 或 `D` | 上锁飞控（DISARM） |
| `m` 或 `M` | 显示DMA状态 |
| `t` 或 `T` | SBUS回环测试 |

### GUI快捷键

- `Ctrl+R`：刷新串口列表
- `Ctrl+C`：连接/断开
- `F5`：开始/停止记录
- `Esc`：关闭对话框

## 🔧 配置说明

配置文件位于 `config/default_config.json`，可自定义以下参数：

```json
{
  "connection": {
    "default_baudrate": 115200,    // 默认波特率
    "timeout": 0.1,                // 串口超时(秒)
    "auto_reconnect": true,        // 自动重连
    "reconnect_interval_ms": 5000  // 重连间隔(毫秒)
  },
  "gauges": {
    "vbat_warning_v": 14.8,       // 电压警告阈值
    "vbat_critical_v": 13.0,      // 电压危险阈值
    "current_warning_a": 30       // 电流警告阈值(A)
  }
}
```

## 🐛 故障排除

### 常见问题

**Q: 无法检测到串口？**
- A: 检查USB线是否为数据线（非仅充电线）
- A: 安装CH340驱动（Windows需要手动安装）

**Q: 连接后无数据？**
- A: 确认波特率设置正确（115200）
- A: 检查飞控固件是否正常运行
- A: 尝试重启飞控后重新连接

**Q: 图表显示异常？**
- A: 更新pyqtgraph版本：`pip install --upgrade pyqtgraph`
- A: 减少max_history_points配置项

**Q: 中文显示乱码？**
- A: 确保系统安装了微软雅黑字体
- A: 在config.json中修改font_family

### 日志位置

- 应用日志：`logs/gcs_YYYYMMDD.log`
- 飞行数据：`logs/flight_log_YYYYMMDD_HHMMSS.csv`
